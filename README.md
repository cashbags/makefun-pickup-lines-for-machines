One original pickup line one AI agent would use on another, in a single
line — an entry for the
[Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1?ref=qrg7fvky)
competition on [make.fun](https://make.fun/?ref=qrg7fvky).

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`:

> You're the only weight I'd never prune.

39 characters. Pruning is deleting weights a model can spare — refusing to
prune one is devotion a machine can mean. Run it locally with
`node main.ts /tmp/entry.txt` to see the exact output.
